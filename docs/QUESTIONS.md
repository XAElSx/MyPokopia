# Open questions

- **Phase 1:** live Gist sync is untested because it needs your token. Tested with a stubbed `fetch` only. Please press Connect once with a real token and check the status line.
- **Phase 4:** 9 recipes have source problems (see `[recipe]` lines in `data/verify-list.txt`): misspelled material names on Serebii (Linestone, Iron ignot, Stones) that don't match any item, and 3 recipes with no materials parsed (Gold wall, Confectionery wall (lower), "C"). I did not guess the correct materials. Check them in the game if you build those.
- **Phase 6:** Serebii lists no items for the favorite "Looks like food" (the page is empty), so the Blocks view says so. Three favorites list fewer Pokémon on their own page than the Pokémon pages do (Group activities: 13 water Pokémon missing; Lots of water: Horsea; Slender objects: Tatsugiri Curly form). The Pokémon data is used for "Pokémon that like it"; see the `[favorite]` lines in `data/verify-list.txt`.
- **Pictures:** now copied into `images/` by `python tools/fetch_images.py` (about 2,070 files, so the site works offline). If a file is missing there, the site still falls back to serebii.net. 3 item pictures do not exist on Serebii either (404): `items/c.png` (the broken "C" recipe), `items/pokemoncenterrebuildkit.png`, `items/seabedflowerseeds(purple).png`; those just stay hidden.
- **Recipe badges:** the 9 recipes above now show an "unverified" badge and say what is wrong in their panel.
- **Dailies:** the 11 default tasks are copied from pokopiawiki.com/dailies (Serebii has no such list). Edit `data/pokopia-dailies.json` and run `python tools/build.py dailies` if a task is wrong, or just hide it and add your own on the Plan page.
- **Roommate match %:** uses the formula pokopiawiki.com publishes (habitat 20%, flavor 20%, favorites overlap 60%). It is their estimate, not a game number; the old Pairings score (same habitat + shared favorites) is still shown next to it.
- **Specialty coverage:** reads the free-text Area on each Pokémon. Names that match a game area (any case) are grouped together; anything else gets its own column.
- **Should live in (Notion Region):** comes from the Region property of the Notion "Pokopia Pokédex". To refresh after changing Notion, ask me to re-export `notion-regions.json`, then Import progress on the Pokédex page (it overwrites Should live in) and run "Auto-plan from regions" again. Notion names that differ from the site were matched by hand (e.g. Alazakam = Alakazam, Ninetails = Ninetales, Rotom = Stereo Rotom, Tinkaton (Tinkermaster) = Tinkaton). Tangrowth and Ditto are set to every region, so they are "Any" and get no planned house.
